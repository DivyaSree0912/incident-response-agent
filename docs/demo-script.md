# Incident Response Agent — Demo Script

## Goal

Demonstrate how a resolved incident can be retained as persistent memory
and later recalled when a similar incident occurs.

## Demo Flow

### 1. Create Incident 1

Create or select the first incident and display its details.

### 2. Investigate Incident 1

Run the investigation for Incident 1.

Show the incident details and the investigation result.

### 3. Resolve Incident 1

Resolve the incident and record the resolution information.

### 4. Retain Incident 1

Store the resolved incident experience in Hindsight using Retain.

This creates persistent memory that can be used later.

### 5. Create Incident 2

Create a second incident with symptoms similar to Incident 1.

### 6. Recall Historical Memory

Use Hindsight Recall to retrieve relevant historical incident information.

### 7. Show Historical Evidence

Display the historical incident or evidence returned by Recall.

### 8. Investigate Incident 2

Run the AI agent using:

- Current incident details
- Relevant historical evidence

### 9. Show Recommendation

Display the investigation result and recommended action.

## Key Point to Demonstrate

The important part of the demo is the memory loop:

Incident 1 → Resolve → Retain → Persistent Memory

Then:

Incident 2 → Recall → Historical Evidence → Investigation

This demonstrates how previous incident experience can be reused during
a later investigation.
